# 🍦 Transify — AI-Powered Translation Tool

> A pastel gelato-themed translation web app powered by AI for smooth, context-aware translations.

---

## ✨ Overview

**Transify** is a beautifully designed translation website that combines **modern UI aesthetics** with **intelligent AI translation**.

Built with a soft **Gelato Days color palette** and powered by the **Claude API**, Transify delivers translations that feel natural, contextual, and human-like — not robotic.

---

## 🎨 Design Highlights

* 🍑 Soft pastel gelato color palette (peach, rose, mint, lavender, butter, sky, lilac)
* 🌫️ Animated floating blur blobs background
* 🍡 Bouncing gelato-style UI elements
* 🧊 Glassmorphism card with frosted UI
* ✨ Elegant typography (Playfair Display + DM Sans)

---

## 🚀 Features

* 🌍 **40+ Languages Supported**
  Includes Tamil, Hindi, Tagalog, Swahili, and more

* 🤖 **AI-Powered Translation (Claude API)**
  Context-aware, natural-sounding output

* 🔍 **Auto Language Detection**
  Automatically detects input language

* 🔁 **Swap Languages Button**
  Instantly flip source and target languages

* 📋 **Copy to Clipboard**
  One-click copy with confirmation

* 🔊 **Text-to-Speech**
  Listen to translated output

* 🗑️ **Clear Input**
  Reset everything instantly

* ⌨️ **Keyboard Shortcut**
  Press `Ctrl/Cmd + Enter` to translate

* 🔢 **Character Counter**
  Supports up to 2000 characters

* ⚠️ **Error Handling**
  Friendly and user-readable error messages

## ⚙️ Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/transify.git
   ```

2. Navigate to the project folder:

   ```bash
   cd transify
   ```

3. Add your API key in `config.js`:

   ```javascript
   const CONFIG = {
     CLAUDE_API_KEY: "YOUR_API_KEY_HERE"
   };
   ```

4. Run the project using a local server:

   * Use **Live Server (VS Code)** or any local server
